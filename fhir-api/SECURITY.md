# Security policy

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/FAV-Innovation-and-Technologies/SALUDATA/security/advisories/new).

Include the affected commit or version, a minimal synthetic reproduction, expected behavior and impact. Do not include patient records, credentials or production logs. Coordinate disclosure with maintainers before publishing exploit details.

If private reporting is unavailable, ask a maintainer for a private reporting route without posting technical details in a public issue or pull request.

Local defaults are for synthetic development data. Authentication, authorization, TLS, network isolation, data retention, backups and clinical or regulatory suitability require deployment-specific validation. See the module's development notes for known limitations.
